
# 🌙 Pip's Midnight Nursery

A playful, responsive portfolio for Pip, a fictional Junior Dream Engineer.
This project combines a whimsical, early-web-inspired visual style with
interactive elements built using HTML, CSS and JavaScript.

## ✨ Features

- Responsive layout for desktop and mobile
- Custom CSS character illustration
- Animated stars and floating elements
- Day/night theme toggle
- Three interactive dream invention cards
- Visitor dream message interaction
- Hidden Easter egg with keyboard and mouse access
- Accessible navigation, labels and reduced-motion support

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Alternatively, use VS Code Live Server.

No backend or package installation is required.

## 💡 Project Story

I wanted to create a tiny digital world that feels like a playful,
dreamy corner of the early internet. Pip's nursery uses bright details,
animated stars, oversized interactions and a hidden surprise to make
visiting a simple website feel like exploring a small storybook.

I focused on keeping the project lightweight, responsive and usable
while making the design feel personal and memorable.
